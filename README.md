# Red Herring Phishing Derby

## Project overview

The Red Herring Phishing Derby is an educational cybersecurity awareness website for an intern-led phishing simulation campaign. Participants practice recognizing suspicious email, reporting potential phishing attempts, and building safer email habits through friendly competition.

This is a static demonstration website. It does not send email, collect participant information, or calculate live scores.

## Pages

- `index.html` - Program introduction and overview.
- `about.html` - Intern team, project goals, progress, and training video placeholders.
- `rules.html` - Participation guidance, reporting steps, and scoring rules.
- `leaderboard.html` - Fictional sample standings and top performers.
- `contact.html` - ITS Team contact guidance, placeholder resources, and FAQs.

## Purpose

The project helps participants recognize phishing emails and practice reporting them. It was designed and developed by ITS interns as part of the SDCOE ITS Internship Program, giving interns experience planning and presenting a public-facing educational project.

## Files

- `index.html`, `about.html`, `rules.html`, `leaderboard.html`, and `contact.html` contain the five semantic HTML pages. Each page uses the shared navigation, stylesheet, JavaScript, logo, and footer.
- `styles.css` contains the shared colors, typography, page layouts, responsive styles, and accessibility states.
- `script.js` controls the mobile navigation and the training-video placeholder previews.
- `images/redherring_logo.png` is the navy fishing-pole logo used in the site header and home-page introduction.

## Open locally

1. Open the project folder in Visual Studio Code or another editor.
2. Open `index.html` in a web browser. Because the site uses relative file paths and no build tools, it can be viewed directly.
3. Use the navigation links to open the About, Rules, Leaderboard, and Contact Us pages.

## Intern project

ITS interns created the Red Herring Phishing Derby to make cybersecurity awareness practical and approachable. The campaign uses simulated phishing emails for learning, rewards reporting, and encourages participants to use safe email habits. Training-video and resource links on this demonstration site are placeholders for materials selected by the ITS Team.

## Sample data notice

All names and scores on the leaderboard are fictional sample data for demonstration purposes only. They do not represent real participants or actual campaign results.
